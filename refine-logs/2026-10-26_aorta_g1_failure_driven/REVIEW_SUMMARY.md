# Review summary

最关键的审查收益是阻止了一条表面漂亮但错误的理论桥：逐样本pairwise错排界不能推出一般多候选随机
效用下的总体Bayes排序一致性。方案因此从“设计新pairwise loss”收缩为“用proper conditional-mean目标
资格化现有scorer”，并把loss明确降级为实验基础设施而非论文创新。

最终保留的第一性链条是：机会存在 → 决策信息在输入中可辨识 → 函数类可表达 → 优化可找到 → 组外
可泛化 → 正确视觉提供增量 → 差异查询结构优于匹配基线 → 外观变化下转化为行为收益。任何一层失败
都不能用下一层的复杂模块掩盖。
