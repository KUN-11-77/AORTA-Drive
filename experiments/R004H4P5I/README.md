# R004H4P5I realized-geometry interface sentinel

This fit-only blocked sentinel uses anchor index zero from each of the first eight frozen fit
recording groups. It is an implementation exercise, not a prevalence estimate: the
recording group is the experimental unit, anchors are not treated as independent samples,
and no significance or performance claim is permitted.

The run binds each exact metric cache to its node-label artifact, derives the vehicle body
from the cache's official vehicle parameters, checks analytic rear-axle corners against
NAVSIM preprocessing, executes six frozen desired references through the official
LQR+bicycle operator, and applies intent, continuous disk-sweep, non-inclusion and teacher
lower-bound contracts to the realized 0.1-second trajectories.

PASS only permits registration of a 128-anchor fit-only preflight. Development,
calibration, test, target-domain access and method-performance claims remain prohibited.
