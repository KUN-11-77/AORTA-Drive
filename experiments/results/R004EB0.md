# R004E-B0 One-Anchor Visual Replay

- **Status:** completed
- **Formal verdict:** PASS for one-anchor visual-interface replay only
- **Generation and audit revision:** `9cdc7c21675c5b25df8adfcf94a9a9a71b38740a`
- **Frozen configuration SHA-256:** `1f93b85201c6cb47c37acd5751f1d1a1acde8ec8f374cf00f63b6bf03cd98382`

## Question

R004E-B0 asked whether the exact R004B visual interface can be persisted without
materializing the approximately 169 GiB redundant node-slot tensor, and whether two
independent builds replay at the byte level before any group-scale extraction is allowed.

The frozen factorization stores each normalized last-four-layer DINO map as raw BF16 bit
patterns with shape `[1280,18,32]`, plus one float64 `[4096,12,2]` patch-coordinate array
and one Boolean `[4096,12]` support mask per anchor. No PCA, channel projection, lossy
quantization, padding or clamping is used. Invalid coordinates are stored as exact zero
with an explicit false mask.

## Results

Two independent output directories were built from the same frozen train anchor and its
12 history/camera slots. Both runs used the checkpoint SHA-256
`7c1da9a54b3bdb333f5ebc42e404b7f19b1b5bed504877623c9dc87397f41488`
and the canonical 151-file DINO Python-source-tree SHA-256
`dde435450cdc79eaddcd11039ab90d942f6fb08770b5ee3998a81240d8cf1bf8`.

- all 12 dense-feature artifacts and both projection artifacts had identical file hashes;
- both logical manifests had SHA-256
  `ea167866afa4ec08a64480d4304a621a9c4b7e5dce032bb7d55b4ea973a68c7ee`;
- each build occupied 18,532,096 bytes and produced 12 unique image features;
- both independent audits reported zero feature/projection hash or shape failures;
- masked materialization was finite and invalid slots were exact zero;
- the NumPy sampling oracle and independent torch `grid_sample` path differed by at most
  `1.9073486328125e-6`, below the pre-registered `1e-5` tolerance;
- the exact anchor matched the frozen R004E-A label manifest; calibration, source test and
  target-domain data were not accessed.

The evidence bundle SHA-256 is
`43a62eeae31c1cfe31fe3be05e908e40abd4c4ff71d771a2af19e9376770cee2`.

## Falsification and repair

Before EB0, a shell-generated DINO source-tree digest and the path-sorted Python canonical
digest disagreed despite covering the same 151 files. The shell digest was rejected as
locale-sensitive provenance, the experiment did not start, and the Python canonical
manifest hash was frozen. A separate remote verification command initially failed because
its dictionary-key quoting was malformed; it was not counted. File-list byte replay and
logical replay were then checked by successful `set -e` commands.

## Claim boundary and next gate

R004E-B0 qualifies only one-anchor deterministic storage, exact masking and the runtime
sampling interface. It does not establish 90-group coverage, training throughput, learned
accuracy, calibration, certificate utility, OOD robustness or Gate B success. R004E-B1 may
now process eight complete recording groups; R004E-B2 remains blocked until that passes.
