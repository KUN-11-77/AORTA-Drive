## Preserved execution issue

The first local pytest command stopped during test collection because the repository
`src` directory was absent from that interpreter's import path. No registered assertion
ran. The rerun added `src` only inside the process, without modifying the environment or
the registered code/config, and all checks passed.

## What changed scientifically

R004E-G closes the new arithmetic and protocol interface that R004E-F required:

1. residual soundness starts from four represented node values, not already-rounded
   gradients；
2. learned scale cannot be trained by the invalid tail-augmented properness argument；
3. historical train groups are proxy-cal only；
4. any invalid calibration group fails the entire variant；
5. edge allocation must later beat both uniform and per-observation pooled controls on
   the same potential and common task-opportunity denominator.

## Next gate

Freeze R004H before any new training. It must specify the fresh fit-only potential replay,
scale-head checkpoint rule, pooled/uniform/evidence controls, common opportunity oracle,
all metric constants, invalid handling, compute budget and one-read development decision.
Official calibration remains sealed until the final model and score construction are
irrevocably frozen.
