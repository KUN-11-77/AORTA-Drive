## Question and frozen answer

R004D asked whether a legal, candidate-free predictor could consume the exact R004B
masked evidence tensor, represent only the task-identifiable quotient field, optimize an
edge-tail-aware target and select a checkpoint without consulting calibration/test data or
candidate outcomes.

The frozen probe uses shared $1280\rightarrow64\rightarrow64$ slot projection, learned
camera/history context, masked soft attention, an explicit all-missing token and evidence
fraction, followed by a 96/128/192-channel two-scale residual U-Net. Invalid slots receive
exactly zero fusion weight; hard best-view selection is prohibited. The final node potential
has its exact spatial mean removed, choosing one representative of
$\mathbb R^{|\Omega|}/\operatorname{span}\{\mathbf 1\}$.

Training is frozen to graph-gradient Huber plus a centered log-sum-exp edge-tail surrogate.
This surrogate is not a statistical bound. After every epoch, the exact maximum metric
edge residual over all 16 frozen anchors is computed for each of the 24 development
recording groups. Checkpoints are selected lexicographically by the mean of the five worst
group maxima, the all-group mean and the earliest epoch. The 384 development anchors are
therefore not treated as 384 independent validation samples.

## Structural and resource results

The local unit suite exercised common-shift invariance, all-missing behavior, invalid-slot
invariance, edge ordering, gradient flow and the recording-group checkpoint rule. The full
suite passed 88/88 tests.

The clean resource-scale audit ran one $1\times4096\times12\times1280$ input and a complete
forward/backward pass on an NVIDIA RTX 3090:

- 4,000,225 trainable parameters;
- output shape $1\times64\times64$ with finite output and finite gradients;
- peak allocated CUDA memory: 1,895,916,032 bytes;
- two-forward replay maximum error: 0;
- changing every invalid-slot storage value from zero to 1000 changed the output by 0;
- maximum absolute output spatial mean: $1.86\times10^{-9}$;
- 16 forced all-missing nodes exercised the learned missing-token path.

The tensor was deterministic synthetic data with the exact frozen R004B dimensions. This
audit verifies interface composition and resource feasibility, not semantic prediction.
R004B separately verified that the frozen DINOv3-H+ produces finite 1280-channel token
fields under the frozen rectangular preprocessing.

## Falsification and repair

The first RTX 3090 attempt was rejected because PyTorch deterministic algorithms were
enabled without CUDA's required cuBLAS workspace contract. A random seed alone was
therefore insufficient. Before the clean audit, the protocol was repaired to set
`CUBLAS_WORKSPACE_CONFIG=:4096:8` before the first CUDA linear-algebra operation. No result
from the failed revision was reused.
