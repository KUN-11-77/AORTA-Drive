# R004H2D Result — Scale-interface conditioning diagnosis

## Decision

**DIAGNOSIS RESOLVED: `TRUNK_ACTIVATION_SCALE_DOMINANT`.** All eight frozen anchors met
the preregistered activation-scale vote. This authorizes registration of one H2 revision
whose only architectural change is a magnitude-gauge removal at the scale branch input.
It does not authorize H3 or any calibration/utility claim.

## What was measured

The diagnostic used the four lowest-index anchors from the first fit group and the same
four from the first selection group. For each anchor it computed the exact initial scale
gradient, verified it against autograd, and analytically replayed AdamW's first update on:

1. the frozen raw Stage-P spatial map; and
2. the same map divided by its uncentered per-observation global RMS.

No optimizer was constructed, no parameter was mutated and no checkpoint was written.

## Result

| Quantity | Observed range / median |
|---|---:|
| Raw feature RMS | `1776.13`–`2195.25` |
| Median raw full gradient norm | `3948.5234` |
| Median RMS-normalized full gradient norm | `2.0259` |
| Median gradient-norm reduction | `2026.85×` |
| Raw first-step max absolute logit change | `82.20`–`132.62` |
| RMS-normalized first-step change | `0.0413`–`0.0653` |
| Raw first-step cap fraction | `0.7532`–`0.9330` |
| RMS-normalized cap fraction | exactly `0` on 8/8 anchors |
| Median raw safe learning rate for a 0.25 logit limit | `6.91e-7` |

Vote counts were activation scale `8/8`, parameterization `0/8`, and learning-rate-primary
`0/8`. The bounded-sigmoid derivative at the shared 1 m initialization is only about
`0.94×` the log-scale derivative, so it cannot explain the initial gradient amplification.
Although reducing the learning rate could numerically suppress the raw step, it is not the
primary diagnosis because the registered learning rate becomes stable under magnitude-only
normalization with all other quantities unchanged.

## Architectural implication

The frozen Stage-P representation has an arbitrary high-magnitude activation gauge that is
harmless to its own potential head but enters the new 1x1 scale-head Jacobian directly.
The next candidate must remove only this nuisance magnitude before the scale branch:

\[
\bar h(X)=\frac{h(X)}{\sqrt{|h|^{-1}\sum_i h_i(X)^2}}.
\]

It must not center features, alter the potential path, add trainable normalization, change
the objective, tune the learning rate, or open a new data role. This is a targeted interface
repair, not a new uncertainty claim.
