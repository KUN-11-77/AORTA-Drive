# AORTA 假设品味门：防止为局部假设钻牛角尖

状态：`PRE_RESULT_GOVERNANCE__NOT_SCIENTIFIC_EVIDENCE`。

## 1. 不随某个算法成败改变的第一性问题

AORTA 的稳定研究对象不是低秩、某个 layer、某个 rank 或 CPTR，而是：在物理场景与历史保持不变时，
外观改变为何会改变冻结 planner 的行为；哪些变化位于决策等价类内，哪些变化实际介导行为；测试时可用
视觉证据能否恢复后者。写成条件效应：

\[
\Delta_A O(S,H)=f\!\left(\phi(g(S,A_c)),H\right)
                  -f\!\left(\phi(g(S,A_s)),H\right).
\]

低秩子空间只是对该效应结构的一种压缩假设。它若被否定，应淘汰该接口，而不是改写第一性问题。

## 2. 六项方法假设资格

任一候选假设进入架构设计前，必须同时回答：

1. **现象广度**：是否解释多个 recording group、外观和至少两个 planner/架构，而非单 checkpoint 特例？
2. **解释压缩**：是否用少量可解释自由度统一多个已观察失败，而非为每个失败增加独立模块？
3. **可区分预测**：是否给出与 matched baseline、捷径解释和空假设不同的预注册预测？
4. **算法必要性**：由该假设导出的结构是否在相同输入、backbone、参数/FLOPs 和训练预算下不可替代？
5. **可观测与可部署**：训练与推理变量是否因果可用，且 batch-1 P95、拒判和 clean no-harm 可闭合？
6. **反例边界**：是否明确什么结果会停止分支，而不是通过升 rank、调阈值、删组或新增 loss 挽救？

只满足数学自洽而没有第 1、3、4 项，不构成有价值的方法理论；只获得 benchmark 增益而没有第 3、5、6
项，不构成可信机制。

## 3. 假设预算与停止规则

每个结构假设最多获得：

- 一次结果前冻结的失败分解，用来区分估计、优化、有限样本与结构性失败；
- 若分解支持明确的新预测，再获得一次前瞻确认；
- 确认失败后停止该假设家族，不允许用事后阈值、best-of-restarts 或更大容量覆盖旧裁决。

形式上，结构假设 \(H\) 只有在独立确认数据上同时满足

\[
E_{\mathrm{mechanism}}(H)=1,\quad
E_{\mathrm{necessity}}(H)=1,\quad
E_{\mathrm{behavior}}(H)=1
\]

才进入论文主方法。诊断证据不能替代其中任一项。

## 4. R006 分支的当前适用

| 假设 | 当前地位 | 后续边界 |
|---|---|---|
| 所有折共享同一固定最小 rank | 已被 R006V0 否定 | 永久停止；rank 32 事后通过不能复活 |
| 估计器/优化不稳定 | R006V0F已支持当前估计器不稳定 | 记录为失败机制；Fantope不再进入主实验 |
| 共享方向核心但有效维数异质 | 未确认且不再作为当前主线 | 不再追加rank/seed实验；仅保留历史假设 |
| 输入条件化 tangent/VJP interface | 尚未获得方法资格 | 只有DINO接口审计证明局部task restriction必要，且击败Gram/direct residual时才解锁 |
| 不存在稳定低维结构 | 合法竞争解释 | 停止 subspace/CPTR；回到直接任务敏感证据建模，不以继续升 rank 规避 |

R006V0F 已作为低秩假设家族的终止性分流实验。当前主线转为冻结DINOv3-H+接口因果审计；只允许
由`AMPLIFICATION`、`COMPRESSION`或二者混合的前瞻证据解锁一个最小方法。`UNRESOLVED`不授权网络搜索。

## 5. 一分钟故事的稳健性检查

合格故事不依赖某个任意 rank：**稳定视觉特征不必然产生稳定决策，因为冻结 planner 只对部分外观漂移
敏感；我们先因果定位这些任务敏感效应，再只学习其中组外可恢复、可干预的部分，并以选择性修复避免
无证据干预。**

若实验最终显示不存在稳定、可恢复的任务敏感结构，这个故事必须被证伪；不能把“审计严谨”本身写成
方法贡献。Best-Paper 水准来自广泛发现、必要结构和行为闭环同时成立，而不是公式数量或系统复杂度。
