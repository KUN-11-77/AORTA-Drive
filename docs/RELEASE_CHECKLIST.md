# Public Release Checklist

- [ ] Repository owner selects a license.
- [ ] Author names, affiliations, and contact are confirmed.
- [ ] `CITATION.cff` is added with verified metadata.
- [ ] Security-sensitive and private paths are absent.
- [ ] Dataset terms permit every released artifact.
- [ ] Checkpoints have provenance and redistribution permission.
- [ ] All headline numbers pass claim-to-evidence audit.
- [ ] Installation is verified in a clean environment.
- [ ] Reproduction commands work from a tagged commit.
- [ ] Limitations and modeled safety scope are prominent.
